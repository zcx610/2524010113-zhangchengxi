# 强化学习学习文档

---

## 一、多臂老虎机

多臂老虎机（Multi-Armed Bandit, MAB）是强化学习中最基础的决策问题，核心矛盾在于**探索（Exploration）**与**利用（Exploitation）**的权衡。

1. **累积奖励与累积遗憾**
   - 最大化累积奖励等价于最小化累积遗憾（Regret）。遗憾定义为：当前选择与最优杠杆之间的期望奖励差距随时间的累积和。

2. **增量更新估计预期奖励**
   - 一般采用增量式更新方式，每次只需维护一个累计均值，无需存储全部历史数据，**时间复杂度和空间复杂度均为 O(1)**。

3. **ϵ-贪婪算法（ϵ-Greedy）**
   - 每次以概率 `1-ϵ` 选择当前估计期望奖励最高的杠杆（利用），以概率 `ϵ` 随机选择一个杠杆（探索）。
   - 参数 `ϵ` 控制探索与利用的平衡。

4. **上置信界算法（UCB, Upper Confidence Bound）**
   - 利用 **Hoeffding 不等式** 为每个杠杆的奖励估计值加上一个置信上界，优先选择"不确定性高"或"均值高"的杠杆，实现更优雅的探索-利用平衡。

5. **Thompson Sampling 算法**
   - 一种基于 **贝叶斯蒙特卡罗采样** 的方法。为每个杠杆的奖励概率维护一个后验分布，每轮从中采样，选择采样值最高的杠杆执行。理论上在多种场景下能达到更低的遗憾界。

> 探索-利用的权衡贯穿整个强化学习。ϵ-Greedy 简单粗暴但有效；UCB 用置信区间量化不确定性；Thompson Sampling 则从贝叶斯视角做概率采样，三者体现了从"频率派"到"贝叶斯派"的不同思路。

## 二、马尔可夫决策过程

马尔可夫决策过程（Markov Decision Process, MDP）是强化学习的数学基础框架，用元组 `<S, A, P, R, γ>` 描述。

1. **马尔可夫性质**
   - 某一时刻的状态仅取决于前一时刻的状态（以及动作），与更早的历史无关。这是"无记忆性"的假设，使得问题在数学上可解。

2. **马尔可夫链**
   - 一个元组 `<S, P>` 描述了一个马尔可夫过程，其中 `S` 是状态的有限集合，`P` 是状态转移矩阵（P[s'|s] 表示从 s 转移到 s' 的概率）。

3. **奖励与回报**
   1. **奖励（Reward）**：某个状态的奖励指转移到该状态时可以获得奖励的期望，记为 `R(s)` 或 `R(s,a,s')`。
   2. **回报（Return）**：从第 `t` 时刻状态开始，直到终止状态时，所有奖励的**折扣衰减之和**：
      $$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$$
      其中 `γ ∈ [0,1)` 是折扣因子，决定未来奖励的当前价值。

4. **价值函数（Value Function）**
   - 一个状态的价值 = 从这个状态出发的**期望回报**（未来累积奖励的期望）：
     $$V^\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s]$$

5. **贝尔曼方程（Bellman Equation）**
   - 价值函数满足递归关系：当前状态的价值 = 当前奖励 + 折扣后的下一状态价值：
     $$V(s) = \mathbb{E}[R + \gamma V(S')]$$

6. **动作价值函数（Action-Value Function）**
   - 在状态 `s` 下执行动作 `a` 的期望回报：
     $$Q^\pi(s,a) = \mathbb{E}_\pi[G_t \mid S_t = s, A_t = a]$$

7. **贝尔曼期望方程（Bellman Expectation Equation）**
   - 将策略 π 下的状态价值与动作价值联系起来：
     $$V^\pi(s) = \sum_a \pi(a|s) \left[ R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^\pi(s') \right]$$

8. **蒙特卡洛方法（Monte Carlo）**
   - 一种基于采样的数值计算方法：通过多次完整轨迹的采样，用经验平均来估计价值函数，无需知道环境模型。

9. **占用度量（Occupancy Measure）**
   - 表示在某个策略下，状态-动作对被访问到的概率分布。占用度量是连接策略与环境动态的核心概念，也是后续模仿学习和离线 RL 的理论基础。

10. **最优状态价值函数**
    - 所有策略中能获得的最大价值：
      $$V^*(s) = \max_\pi V^\pi(s)$$

11. **贝尔曼最优方程（Bellman Optimality Equation）**
    - 最优策略满足的方程：
      $$V^*(s) = \max_a \left[ R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^*(s') \right]$$

> 贝尔曼方程是整个强化学习的"万有引力定律"。它把"未来"压缩进"当前"，让我们可以用动态规划的思想逐步求解最优策略。理解 V 和 Q 的区别（Q 多 conditioning 了一个动作）是后续所有算法的基础。

## 三、动态规划算法

动态规划（Dynamic Programming, DP）要求**已知环境模型**（即知道状态转移概率和奖励函数），通过迭代求解贝尔曼方程。

1. **策略迭代算法（Policy Iteration）**

   由两步交替组成，直至收敛到最优策略：

   1. **策略评估（Policy Evaluation）**
      - 固定当前策略 π，反复应用贝尔曼期望方程，迭代计算直到收敛，得到该策略的状态价值函数 `V^π`：
        $$V(s) \leftarrow \sum_a \pi(a|s) \left[ R(s,a) + \gamma \sum_{s'} P(s'|s,a) V(s') \right]$$

   2. **策略提升（Policy Improvement）**
      - 根据贪心法，用当前 `V^π` 重新选取动作，得到新的策略 π'：
        $$\pi'(s) = \arg\max_a Q^\pi(s,a)$$
      - 若 π' = π，则已收敛到最优策略。

   3. **完整流程**：评估 → 提升 → 再评估 → 再提升 → …… 直至策略不再变化。

> 策略迭代的本质是"先看清现状，再贪心地迈一步"。每一次评估都在更准确地评估当前策略，每一次提升都在保证严格改进（除非已经最优）。这就像先画地图再选路，虽然慢但稳。

## 四、时序差分算法

时序差分（Temporal Difference, TD）学习结合了蒙特卡洛的采样思想和动态规划的 bootstrap 思想，**无需环境模型**，用一步或几步的真实奖励 + 估计值来更新。

1. **Sarsa 算法（State-Action-Reward-State-Action）**
   - 用 `ϵ-贪婪` 策略根据动作价值选取动作与环境交互，再用时序差分更新 Q 值：
     $$Q(s,a) \leftarrow Q(s,a) + \alpha \left[ r + \gamma Q(s',a') - Q(s,a) \right]$$
   - 其中 `(s,a,r,s',a')` 正是算法名称的由来。

2. **多步时序差分（n-step TD）**
   - 使用 `n` 步的真实奖励累积，再结合第 `n` 步后的状态价值估计：
     $$G_t^{(n)} = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{n-1} R_{t+n} + \gamma^n V(S_{t+n})$$
   - `n=1` 退化为普通 TD(0)，`n→∞` 趋近于蒙特卡洛。

3. **在线策略 vs 离线策略**
   - **在线策略（On-policy）**：行为策略 = 目标策略（如 Sarsa），学的是"当前策略能做什么"。
   - **离线策略（Off-policy）**：行为策略 ≠ 目标策略（如 Q-Learning），可以从他人的经验/旧策略中学习。

4. **Dyna-Q：基于模型的强化学习**
   - 在 Q-Learning 的基础上，额外维护一个环境模型。每步交互后，既用真实经验更新 Q 值，也用模型模拟的经验（规划）进行额外更新，加速学习。

> TD 学习是 RL 的"心脏"。它不需要等到 episode 结束就能更新（比 MC 快），也不需要知道环境模型（比 DP 通用）。Sarsa 保守（on-policy），Q-Learning 大胆（off-policy），Dyna-Q 则进一步引入"想象"来加速。

## 五、DQN 算法

深度 Q 网络（Deep Q-Network）将深度学习与 Q-Learning 结合，用神经网络拟合 Q 函数，是深度强化学习的里程碑工作。

1. **DQN 核心思想**
   - 用一个神经网络 `Q(s,a; θ)` 来表示最优动作价值函数，利用 Q-Learning 的 TD 误差进行参数更新：
     $$L(\theta) = \mathbb{E}\left[ \left( r + \gamma \max_{a'} Q(s',a';\theta^-) - Q(s,a;\theta) \right)^2 \right]$$
   - 关键技术：**经验回放（Experience Replay）** 打破样本相关性，**目标网络（Target Network）** 稳定训练目标。

2. **Double DQN**
   - 解决 DQN 中对 Q 值的**过高估计（overestimation）** 问题。用主网络选动作、目标网络评估价值：
     $$Q(s', \arg\max_a Q(s',a;\theta); \theta^-)$$
   - 有效降低正偏差，使 Q 值估计更准确。

3. **Dueling DQN**
   - 将 Q 网络拆分为**状态价值流 V(s)** 和**优势流 A(s,a)** 两部分：
     $$Q(s,a) = V(s) + A(s,a) - \frac{1}{|A|}\sum_{a'}A(s,a')$$
   - 在动作空间较大或许多动作价值相近的环境下，能更好地学习动作之间的差异。

> DQN 的出现证明了一件事：RL 可以端到端地从高维感知输入（如像素）学策略。Double DQN 治"盲目乐观"，Dueling DQN 治"动作区分度不够"，三者是递进式改进的关系。

## 六、策略梯度算法

与前几章"先学 Q 值再推策略"不同，策略梯度（Policy Gradient）**直接参数化策略 π(a|s; θ)**，通过梯度上升最大化期望回报。

1. **核心思想**
   - 智能体根据当前策略直接与环境交互，通过采样得到的轨迹数据计算出策略参数的梯度，进而更新策略，使其向最大化期望回报的目标靠近：
     $$\nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta} \left[ \sum_t \nabla_\theta \log \pi_\theta(a_t|s_t) \cdot G_t \right]$$
   - 直观理解：**哪条轨迹总回报高，就增大这条轨迹上各动作的概率**。

> 策略梯度的优势是天然支持连续动作空间和高维动作分布，缺点是方差大、样本效率低。后续 Actor-Critic、PPO 等算法本质上都是在"降低方差"和"提高数据利用率"上做文章。

---

## 七、Actor-Critic 算法

Actor-Critic 是**基于值函数的方法**和**基于策略的方法**的有机结合。

1. **基本结构**
   - **Actor（演员）**：参数化策略 `π(a|s; θ)`，负责选动作，沿梯度方向更新。
   - **Critic（评论家）**：参数化价值函数 `V(s; w)` 或 `Q(s,a; w)`，负责评估 Actor 的表现，提供基线或 TD 误差作为优势估计。
   - 梯度更新中使用**优势函数** `A(s,a) = Q(s,a) - V(s)` 替代原始回报，有效降低方差：
     $$\nabla_\theta J \approx \mathbb{E}[\nabla_\theta \log \pi_\theta(a|s) \cdot A(s,a)]$$

> Actor-Critic 就像"演员+导演"组合：演员负责表演（选动作），导演负责打分（评价值），两者互相促进。这个框架是后续 PPO、SAC 等几乎所有现代深度 RL 算法的基石。

## 八、TRPO 与 PPO 算法

1. **TRPO（Trust Region Policy Optimization）**
   - 属于在线策略学习方法，每次仅使用上一轮策略采样的数据。核心观点：**策略更新步幅太大会导致数据分布剧变，使训练崩溃**。因此通过约束新旧策略的 KL 散度，划定一个"可信任区域"：
     $$\max_\theta \mathbb{E}\left[ \frac{\pi_\theta(a|s)}{\pi_{\theta_{old}}(a|s)} A(s,a) \right] \quad \text{s.t.} \quad \mathbb{E}[D_{KL}(\pi_{\theta_{old}} \| \pi_\theta)] \le \delta$$
   - 理论优雅但实现复杂（需要共轭梯度法等二阶优化技巧）。

2. **PPO（Proximal Policy Optimization）**
   - 简化了 TRPO 的复杂计算，大多数情况下性能更优，是目前最广泛使用的 RL 算法之一。有两种主流变体：
     1. **PPO-惩罚（PPO-Penalty）**：用拉格朗日乘数法将 KL 散度约束直接放入目标函数，变成无约束优化，迭代中自适应更新 KL 系数。
     2. **PPO-裁剪（PPO-Clip）**：在目标函数中直接对概率比进行裁剪，限制新旧参数差距：
        $$L^{CLIP}(\theta) = \mathbb{E}\left[ \min\left( r_t(\theta) A_t,\; \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon) A_t \right) \right]$$
        其中 `r_t(θ) = π_θ(a|s) / π_θ_old(a|s)`。

> TRPO 是"戴着镣铐跳舞"，用硬约束保证安全但代价是计算复杂。PPO-Clip 用简单的截断操作达到了类似效果，工程实现极其简洁，堪称"暴力美学"。这也是为什么 PPO 几乎成了 RL 实验的默认基线。

## 九、DDPG 与 SAC 算法

1. **DDPG（Deep Deterministic Policy Gradient）**
   - 面向**连续动作空间**的深度确定性策略梯度算法。结合确定性策略 + Actor-Critic + DQN 的经验回放与目标网络技巧：
     $$Q(s,a) \leftarrow Q(s,a) + \alpha [r + \gamma Q'(s', \mu'(s';\theta')) - Q(s,a)]$$
   - Actor 输出确定性动作，适合机器人控制等连续控制任务。

2. **SAC（Soft Actor-Critic）**
   - 一种**离线策略**的最大熵 RL 算法。除了最大化累积奖励，还鼓励策略的**熵（随机性）** 最大化：
     $$J = \sum_t \mathbb{E}[r_t] + \alpha \cdot \mathbb{E}[-\log \pi(a|s)]$$
   - 使用**目标 Q 网络**稳定训练，并在 Actor 和 Critic 之间交替优化。
   - 优势：训练稳定、探索充分、对超参数相对鲁棒，在连续控制 benchmark 上长期霸榜。

> DDPG 是"果断派"——输出一个确定动作；SAC 是"纠结派"——刻意保留随机性来探索。实践表明，适度的"纠结"反而让训练更稳、最终性能更高。SAC 的最大熵思想也是连接 RL 与概率推断的一座桥梁。

## 十、模仿学习

当奖励函数难以设计或环境反馈稀疏时，可以直接**从专家示范中学习**。

1. **行为克隆（Behavior Cloning）**
   - 最简单直接的方法：把专家的状态-动作对当作监督学习数据集，训练策略网络拟合专家动作。本质是**最小化行为克隆损失**：
     $$L = \mathbb{E}_{(s,a)\sim D_{expert}}[\| \pi_\theta(s) - a \|^2]$$
   - 缺点：分布偏移（distribution shift）问题——策略一旦偏离专家轨迹，错误会累积放大。

2. **生成式对抗模仿学习（GAIL）**
   - 借鉴 GAN 的思想：用判别器区分"策略生成的轨迹"与"专家轨迹"，用生成器（策略）欺骗判别器。等价于**最小化策略占用度量与专家占用度量的 JS 散度**：
     $$\min_\pi D_{JS}(\rho_\pi \| \rho_{expert})$$
   - 不需要手工设计奖励函数，自动从专家示范中"反推"出合理的奖励信号。

> 行为克隆是"照猫画虎"，简单但容易画虎不成反类犬；GAIL 则是"师徒博弈"，让策略在对抗中逐渐逼近专家水平。模仿学习的核心难点始终是**分布偏移**——如何在不确定的状态下做出接近专家的决策。

## 十一、模型预测控制

模型预测控制（Model Predictive Control, MPC）利用**已知或学习到的环境模型**，在每一步进行短期规划。

1. **打靶法（Shooting Method）**
   - 随机生成 `N` 条动作序列，每条序列的每个动作从动作空间中随机采样，长度为 `H`。用模型推演每条序列的累积奖励，选择最优的那条执行第一步，然后重新规划：
     $$\{a_0^*, a_1^*, \ldots\} = \arg\max_{\{a_t\}} \sum_{t=0}^{H-1} r(s_t, a_t)$$

2. **交叉熵方法（Cross-Entropy Method, CEM）**
   - 维护一个带参数的动作分布（如高斯分布）。每轮采样 `N` 条序列，选出 top-K 条（累积奖励最高的），用它们的统计信息更新分布的均值和方差，逐步将概率质量集中到高回报区域。

> MPC 的优势是"走一步看几步"，天然适合有模型或模型可学习的场景。打靶法是纯随机搜索，CEM 则是"精英筛选+分布更新"，效率更高。两者都体现了"模型+规划"相对于"纯学习"的互补价值。

---

## 十二、基于模型的策略优化

1. **MBPO（Model-Based Policy Optimization）**
   - 核心创新：**不从头用模型推演整条轨迹**，而是只从真实访问过的状态出发，用模型做**短步数（short-horizon）** 的想象推演，再把这些想象数据混入真实数据中训练策略。
   - 短步数限制有效缓解了模型误差随推演长度指数级放大的问题（model bias）。

> MBPO 的精髓在于"有限想象"——模型不完美，那就别让它自由幻想太久。从真实状态出发、只推几步，既利用了模型的预测能力，又控制了幻觉的危害，是 model-based RL 工程实践的典范。

---

## 十三、离线强化学习

离线强化学习（Offline RL）要求**仅从固定的历史数据集中学习策略**，不允许与环境交互探索，是 RL 走向工业落地的关键。

1. **保守 Q-Learning（CQL）**
   - 核心思想：对数据集中**未出现或极少出现的状态-动作对**，人为压低其 Q 值估计，消除外推误差（extrapolation error）的影响：
     $$\min_Q \alpha \cdot \mathbb{E}_{s \sim D, a \sim \mu(a|s)}[Q(s,a)] - \mathbb{E}_{s,a \sim D}[Q(s,a)] + \frac{1}{2} \mathbb{E}[(Q - \hat{Q})^2]$$
   - 第一项是"保守正则项"，迫使 OOD（分布外）动作的 Q 值偏低，策略自然不会选择它们。

> 离线 RL 的最大陷阱是"幻觉"——Q 网络对没见过的数据给出过高估计，策略学到后一执行就翻车。CQL 的思路很直觉：没见过就别高估，宁可保守也别冒险。这也是 RL 从"打游戏"走向"用历史数据做决策"的关键一步。

## 十四、目标导向的强化学习

1. **HER（Hindsight Experience Replay）**
   - 一种**经验回放的修改方式**。当智能体未能达成原始目标时，将数据中的"最终到达状态"重新标记为"新目标"，从而把一次失败的经历转化为一次成功的训练样本：
     - 原始经验：`(s, a, r, s', g)` → 奖励为负
     - 重标记后：`(s, a, r', s', g')` 其中 `g' = s'`，奖励为正
   - 极大提升了稀疏奖励环境下的学习效率。

> HER 的核心洞察非常朴素：即使没达到既定目标，你确实达到了某个地方——那就把这个地方当作目标来学习。这种"事后诸葛亮"式的回放，让智能体从每一次尝试中都能榨取出正面信号，是处理稀疏奖励的神器。

## 十五、多智能体强化学习

多个智能体在同一环境中交互，彼此的策略互相影响，问题复杂度急剧上升。

1. **IPPO（Independent PPO）**
   - 完全**去中心化**：每个智能体独立运行一个 PPO 算法，把其他智能体当作环境的一部分。实现简单但忽略了多智能体间的协调信息。

2. **MADDPG（Multi-Agent DDPG）**
   - 每个智能体维护一个独立的 Actor 网络（DDPG 结构），但**所有智能体共享一个中心化的 Critic 网络**：
     - **训练时**：Critic 能观察到所有智能体的状态和动作，给出全局视角的 Q 值指导。
     - **执行时**：每个 Actor 仅依赖自身局部观测独立决策，实现去中心化执行。
   - 兼顾了训练稳定性和执行时的可扩展性。

> 多智能体 RL 的核心矛盾是"非平稳性"——你学的时候别人也在学，环境一直在变。IPPO 假装没看见别人（简单但粗糙），MADDPG 则在训练时引入全局信息来缓解这一问题（CTDE 范式：Centralized Training, Decentralized Execution），是 MARL 领域最经典的设计模式之一。

## 十六、强化学习与有监督学习的区别

| 维度 | 有监督学习（Supervised Learning） | 强化学习（Reinforcement Learning） |
|------|----------------------------------|----------------------------------|
| **数据** | 带标签的数据集 `(x, y)` | 无标签，通过与环境的试错交互获得轨迹 |
| **目标** | 最小化预测与真实标签的误差 `L = (ŷ - y)²` | 最大化长期累积折扣回报 `J = E[Σ γᵗ rₜ]` |
| **反馈** | 每一步都有即时、明确的监督信号 | 奖励信号稀疏、延迟，可能很久后才知对错 |
| **数据分布** | 独立同分布（i.i.d.） | 数据由策略生成，分布随策略改变而变（非 i.i.d.） |
| **探索** | 不需要探索，数据给定 | 需要主动探索以发现高回报行为 |
| **典型应用** | 分类、回归、检测 | 游戏 AI、机器人控制、资源调度、自动驾驶 |

> 一句话总结：监督学习是"有人教"，强化学习是"自己悟"。前者依赖大量标注数据，后者在试错中从奖励信号里自学成才。两者也正在融合——比如用监督学习预训练策略、用 RL 微调，或用 RL 生成数据来训练监督模型。
