# *Markdown*的学习文档

一、学习过程记录
1. 学习背景
之前写实验报告主要依赖 Word，但存在版本管理困难、格式混乱、代码展示不友好等问题。了解到 Markdown 是技术圈主流的轻量级标记语言，适合撰写结构化文档，因此开始系统学习。
2. 学习路径
  1.阅读 Markdown 官方语法说明
  2.对照教程逐项练习基础语法
  3.学习 Markdown 对 HTML5 的支持规则
3.综合实操：完成本学习文档

二、Markdown 关键知识点总结
1. 标题
\# 一级标题
\## 二级标题
\### 三级标题
2. 段落与换行
   1.段落之间用一个空行分隔
   2.行尾加两个空格实现换行
3. 加粗与斜体
   **加粗**
     *斜体*
      ***加粗斜体***
4. 列表
- 无序列表
- 项目一
- 项目二
  - 子项目
- 有序列表
  1. 第一步
  2. 第二步
  3. 第三步
5. 链接与图片
 [链接文字](https://example.com)
 ![图片描述](./images/screenshot.png)
6. 代码块
   1. 将单词或短语表示为代码，将其包裹在反引号 (`) 中
   2. 单词或短语中包含一个或多个反引号，则可以通过将单词或短语包裹在双反引号(``)中
7. 引用
> 这是一段引用内容。
> 多行引用无需重复符号。
