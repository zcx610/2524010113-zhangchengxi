# *数据集检测*学习文档
1. 项目目标
使用 YOLO11n 训练目标检测模型，识别：
- community_person 本小区人员
- non_community_person 非本小区人员
- electric_bike 电动车

2. 环境
- Python 3.10.11
- Ultralytics 8.4.115
- PyTorch 2.13.0+cpu
- YOLO11n 模型权重 yolo11n.pt
- 使用makesense网站进行数据标注

3. 数据集结构
dataset/
  images/
    train/
    val/
  labels/
    train/
    val/
  data.yaml

4. 训练命令/代码
from ultralytics import YOLO

model = YOLO("yolo11n.pt")
model.train(
    data="dataset/data.yaml",
    epochs=50,
    imgsz=640,
    batch=4,
    name="community_v1-5"
)

5. 验证结果
all:
P=0.93, R=0.931, mAP50=0.931, mAP50-95=0.619

各类别：
community_person: mAP50=0.987
non_community_person: mAP50=0.812
electric_bike: mAP50=0.995

6. 模型权重
best.pt 位于 runs/detect/community_v1-5/weights/best.pt

7. 推理方式
model.predict(source="图片或文件夹路径", save=True, conf=0.25)

8. 改进方向
- 增加 non_community_person 样本
- 增加验证集数量
- 优化标注框精度
- 使用 GPU/CUDA 加速训练
- 尝试更多 epoch 或更大模型
