## 一、OpenCV 常用函数用法

| 序号 | 函数 | 功能 | 示例代码 |
|:---:|------|------|----------|
| 1 | `cv2.imread()` | 读取图像 | `img = cv2.imread("test.jpg")` |
| 2 | `cv2.imwrite()` | 保存图像 | `cv2.imwrite("out.jpg", img)` |
| 3 | `cv2.imshow()` | 显示图像 | `cv2.imshow("win", img)` |
| 4 | `cv2.waitKey()` | 等待按键 | `cv2.waitKey(0)` |
| 5 | `cv2.destroyAllWindows()` | 关闭窗口 | — |
| 6 | 数组切片 `img[y1:y2, x1:x2]` | 图像裁剪 | `cropped = img[y1:y2, x1:x2]` |
| 7 | `cv2.convertScaleAbs()` | 对比度与亮度调整 | `dst = cv2.convertScaleAbs(src, alpha=1.3, beta=30)` |
| 8 | `cv2.GaussianBlur()` | 高斯模糊 | `blur = cv2.GaussianBlur(img, (15, 15), 0)` |

> 其中 `alpha` 控制对比度（>1 增强，<1 减弱），`beta` 控制亮度偏移（正值提亮，负值变暗）。

> 高斯模糊的卷积核 `(15, 15)` 必须为奇数，数值越大模糊程度越高，常用于去噪或隐私保护预处理。

## 二、人脸检测完整流程

### 1. 人脸检测原理（Haar Cascade）

Haar Cascade 是一种经典的基于机器学习的人脸检测方法，核心流程如下：

1. **基于 Haar-like 特征**：通过矩形区域的像素差值来刻画人脸的局部特征（如眼睛比脸颊暗）。
2. **使用积分图加速**：将矩形区域求和的复杂度从 O(n) 降为 O(1)，大幅提升检测速度。
3. **AdaBoost + 级联分类器**：用 AdaBoost 从海量弱分类器中筛选强分类器，再级联成多层过滤结构——前几层快速排除非人脸区域，越往后越精细，兼顾速度与准确率。
4. **OpenCV 内置训练模型**：OpenCV 提供了预训练好的 `haarcascade_frontalface_default.xml` 等模型文件，可直接加载使用，无需从头训练。

> Haar Cascade 虽然速度快、资源占用低，但对侧脸、遮挡和光照变化较为敏感，准确率不如现代的深度学习方案（如 MTCNN、YOLO-Face），但作为入门和理解检测流程非常合适。

### 2. 加载分类器

```python
face_cascade = cv2.CascadeClassifier(
    cv2.data.haarcascades + "haarcascade_frontalface_default.xml"
)
```

> `cv2.data.haarcascades` 是 OpenCV 自带的级联模型路径，拼接文件名即可加载，避免手动管理路径。

### 3. 灰度转换

```python
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
```

> 人脸检测在灰度图上进行即可，因为 Haar 特征不依赖颜色信息。转为灰度还能减少计算量、提升检测速度。

### 4. 执行人脸检测

```python
faces = face_cascade.detectMultiScale(
    gray, scaleFactor=1.1, minNeighbors=5, minSize=(30, 30)
)
```

参数说明：
- `scaleFactor`：图像金字塔的缩放因子，值越小检测越精细但速度越慢。
- `minNeighbors`：每个候选矩形需保留的邻域数量，值越大误检越少但可能漏检。
- `minSize`：最小检测窗口尺寸，过滤掉过小的干扰区域。

> 检测返回的 `faces` 是一个 numpy 数组，每行代表一个人脸的 `(x, y, w, h)`，可直接用于画框或裁剪。

## 三、效果对比分析

| 处理步骤 | 效果描述 | 作用 | 说明 |
|----------|----------|------|------|
| 原图 | 清晰、细节完整 | 原始数据 | 所有处理的起点 |
| 裁剪 | 去除无关区域 | 聚焦目标 | 减少后续计算量 |
| 对比度增强 | 更鲜明 | 提升检测率 | 暗光下效果尤其明显 |
| 全局高斯模糊 | 整体柔和 | 初步隐私 | 简单但不够精准 |
| 人脸检测 | 标记人脸位置 | 验证算法 | 用矩形框标出 |
| 人脸局部模糊 | 人脸不可识别 | 隐私保护 ✅ | 精准模糊，体验更好 |

> 从"全局模糊"到"人脸局部模糊"是一个典型的工程优化思路：先用检测算法定位目标区域，再有针对性地做处理，既保护了隐私，又不影响整张图片的其他内容。
