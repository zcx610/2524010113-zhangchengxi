# 月球登陆器强化学习控制 — 学习文档

---

## 一、环境设计

### 1.1 任务背景

本项目基于 Gymnasium 的 `LunarLander-v3` 环境，目标是通过强化学习训练智能体控制登月器完成**软着陆**。

- **控制动作**：主引擎点火、左右方向引擎控制等
- **状态观测**：通常包括位置、速度、角度、角速度、腿部接触信息等

### 1.2 Base 环境

在 Base 环境中，物理与观测较为理想，无额外传感器噪声和控制延迟。智能体主要学习以下基本着陆逻辑：

- 降低垂直/水平速度
- 保持机体姿态稳定
- 尽量落在指定区域
- 减少燃料消耗

### 1.3 Real 环境二次开发

为更贴近实际控制系统，在给定模板和 baseline 基础上引入更拟真的 Real 环境设定：

1. **传感器噪声**：对状态观测加入噪声扰动，模拟惯性测量、位置/速度估计误差
2. **控制延迟**：动作执行存在延迟，模拟真实执行机构响应滞后
3. **更细粒度奖励设计**：在原始着陆奖励基础上，引导高精度定位、平稳下降、姿态稳定与燃料节约
4. **参考优化方向**：定位精度、机体平稳度、燃料消耗等作为奖励/评估参考。按题目要求，这些参考得分不作为最终打分依据，主要用于指导优化

## 二、算法选择

采用 **PPO（Proximal Policy Optimization）** 算法。

### 2.1 选择理由

1. PPO 对连续/离散控制任务均较稳定，适合 LunarLander 这类控制任务
2. 通过 clipping 限制策略更新幅度，避免更新过激
3. 配合 GAE 和价值函数训练，适合中等规模环境调参和日志分析
4. 模板代码和 Stable-Baselines3 生态支持较好，便于观察 `approx_kl`、`clip_fraction`、`explained_variance`、`value_loss` 等指标

### 2.2 PPO 核心设计理念

1. 使用策略网络输出动作分布，价值网络估计状态价值
2. 通过优势函数更新策略，同时优化价值函数
3. 使用 `clip_range` 约束新旧策略比率，保证训练稳定
4. 通过熵项鼓励探索，通过 KL 近似监控策略变化

## 三、模型设计

| 项目 | 描述 |
|:---|:---|
| **算法** | PPO |
| **策略** | MLP 策略/价值网络，基于 SB3 默认结构进行训练 |
| **观测** | LunarLander 状态观测；Real 环境下观测含噪声影响。后续可扩展动作历史/速度滤波特征以提升延迟鲁棒性 |
| **动作** | 环境原生离散/连续控制接口对应的动作空间 |
| **价值函数** | 与策略共享或配合 PPO 价值头进行训练，通过 `vf_coef` 控制价值损失权重 |
| **随机性处理** | Real 环境引入噪声和延迟，因此训练需提升策略鲁棒性，而非仅拟合理想动力学 |

## 五、最终智能体表现分析

### 5.1 最终模型选取

最终采用约 **2M 步**附近的最优模型。

### 5.2 评估指标汇总

| 指标 | 数值 |
|:---|:---|
| **评估回报** | 约 -3908（稳定在 -3.91×10³ 附近） |
| **评估方差** | 约 ±687 ~ ±878 |
| **回合长度** | 约 70 ~ 71.5 |
| **explained_variance** | 0.699 |
| **value_loss** | 2.53×10⁵ |
| **approx_kl** | 0.0021 |
| **学习率** | 3e-4 |

### 5.3 结果总结

针对更拟真的 Real 环境，在模板与 baseline 基础上对奖励函数、训练参数及日志分析流程进行二次开发。引入传感器噪声与控制延迟后，重新调整 PPO 训练配置，使价值函数拟合效果提升，训练至约 2M 步时评估回报稳定在 -3.91×10³ 附近，`explained_variance` 达到 0.699，`value_loss` 降至 2.53×10⁵，策略更新较稳定。3M 步后出现回报下降与方差增大，因此选取 2M 步附近最优评估检查点作为最终策略。
